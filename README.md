# Long-Term Scan

Long-term investor toolkit with two commands plus a readme guide.

## Commands

- **`scan`** — screens sectors, news, and balance sheets for quality
  companies, identifies each stock's regime on the 3-month (quarterly)
  chart using the 50 SMA, then looks for pullbacks that cross the SMA in
  bullish regimes or confirmed bottoms in bearish ones, with RSI as context.
- **`learn`** — teaches stock market and long-term investing literacy step
  by step.

## Files

- `SKILL.md` — the skill
- `references/` — readme guide, learn curriculum, data sources, resources,
  curriculum-builder prompt, screening criteria
- `scripts/quarterly_sma.py` — quarterly SMA helper

## Disclosure

Educational research, not financial advice. Never place orders, even if
trading tools are connected.
